Anki中英文消消乐
一款结合单词记忆与消消乐机制的 Web 端背单词工具。通过左右匹配英文与中文释义，配合基于 FSRS（间隔重复）改进的记忆算法，辅助用户进行词汇记忆。

纯前端实现，所有数据（词库、学习进度、设置）均保存在本地浏览器 LocalStorage 中，无需联网。

功能
匹配玩法
屏幕分为左右两列，随机分布英文单词与中文释义，点击左右对应的卡片进行消除。

当前屏幕的词汇匹配完成后，自动加载下一组词汇。

配对成功展示特效与音效；配对错误会高亮显示正确选项并晃动提示。

配对错误的词汇会在当前组内重新排队。

记忆算法 (FSRS)
根据每次匹配的正确率，计算单词的记忆稳定性（Stability）、难度（Difficulty）和下次复习时间（Due Date）。

基于遗忘曲线模型估算每个单词的掌握程度百分比。

支持自定义每日学习数量，系统会自动计算预计完成天数。

词库导入与处理
支持导入 .xlsx、.csv、.tsv、.txt 文件。

XLSX 导入提供预览：自动识别工作表、起始行和词汇列（支持手动调整），并过滤表头、广告、无效行和重复单词。

导入时自动识别并纠正中英文列颠倒的情况。

支持将当前词库、学习进度、错词统计导出为 JSON 文件进行备份或恢复。

进度追踪
首页展示“今日学习进度”与“总词库掌握进度”双进度环。

词汇列表页支持：

按名称、错误频率排序。

关键词搜索（中英文）。

“只看错词”筛选模式。

一键复习所有错词。

查看每个单词的错误次数和掌握程度。

一键导出当前词库为 TSV 格式。

每日目标完成后，支持“加量学习 +10”。

外观定制
明暗模式切换（支持跟随系统时间自动切换）。

内置多种主题色，支持通过调色盘自定义主题色。

支持上传本地图片作为网页背景。

响应式布局，适配手机端、平板和电脑端浏览器。

使用说明
准备包含“英文单词”和“中文释义”的 Excel（.xlsx）、CSV 或 TXT 文件。

点击页面右上角的设置按钮，或在新手引导页选择“导入文件”。

导入 Excel 文件时会弹出预览窗口，请确认工作表、起始行和列是否识别正确。

设置每日学习数量（如 20 个/天）。

点击“开始背单词”，在左右两列中匹配对应的中英文卡片。

技术栈
前端核心：HTML5, CSS3, Vanilla JavaScript (ES6+)

数据解析：JSZip (用于读取 XLSX 文件的底层 XML 结构)

本地存储：浏览器 localStorage

音效系统：基于 HTML5 Audio 对象

数据说明
本应用无后端服务器。词库文件、学习进度、错词记录、外观设置全部保存在浏览器本地（localStorage）中。清理浏览器缓存或更换设备会导致数据丢失，请使用设置中的“备份学习进度为 JSON”功能定期保存数据。
